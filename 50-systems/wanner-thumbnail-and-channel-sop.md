# Wanner Cash Cow — Thumbnail + Channel SOP (Chicago 08-13)

## Thumbnail principles (Daniel's generic rules)
- Two goals ONLY: (1) stop the scroll, (2) give ~1 second to persuade the click.
- Simpler always beats complex/saturated. Too much text = a classic mistake.
- Vibrant, readable text: yellow and red, easily-readable concepts. Text must COMPLEMENT the title, not repeat brand clutter on the thumb.
- Always study competitors first: if THEY succeed with that thumbnail style, the audience is triggered by that style. Find WHY they're triggered. Then copy the winning elements but CHANGE something small (e.g. background color) so you feel different from them ("people think it's something new") while covering the same topics.

## Thumbnail ASSET workflow (repeatable)
1. Save 2 example thumbnails from a competitor that works in your niche.
2. Give them to Claude + the target title. Ask Claude to: analyze the elements/text style/generic style, then WRITE an image-generation prompt that reproduces the thumbnail style for YOUR title (specify the word to write on it + what object replaces the reference's object). Provide the examples as reference in the image tool.
3. Generate in an image tool. Options: ChatGPT (very good now), Magnific (one subscription, many models), Google Flow with Nano-banana Pro / Nano-banana 2. Daniel uses Magnific mostly.
4. Make your OWN master prompt once a style works — give the style back to Claude so it saves all styling and from then on you only input a title and get back a usable image-gen prompt. Then you stop needing random competitor channels.
5. Iterate: "now change background to white / change steele / make subject bigger / use vintage yellow text."
- AVOID prompting the AI to render TEXT at generation time — generate the clean image first, then place text in Canva/Promo (or add text in a second pass). Lower results if you force text during generation.

## AI avatar → thumbnail (Marvens' asked question)
Problem: Vidrush renders avatar in video but NOT in thumbnails; VA's ChatGPT thumbs "look like ChatGPT."
Daniel's fix (the photoshoot method):
1. Generate MULTIPLE images of the SAME avatar from different angles / a photoshoot set (Claude writes 4-5 detailed image-gen prompts "photoshoot of this person from different angles", reference the one avatar image you have). Save the set.
2. Always provide that avatar photoshoot set as REFERENCE whenever generating a thumbnail, and include in the prompt: "put THIS specific person on the thumbnail." (ChatGPT or Nano-banana Pro.)
3. This keeps the same person across all thumbnails (consistency) because you reference the same stored set every time — better than one high-res blit-in.

## Channel launch / Gmail isolation (Daniel's guidance)
- ALWAYS create a NEW Gmail account per channel. Never two channels on the same Gmail — Google associates them; problems on one can hit the other.
- Warm up the new Gmail 4-5 days as a REAL viewer (not 30-sec clicks): watch videos long, subscribe, comment a little. Then set channel art and post.
- Don't delete the old channel until the NEW one is fully set up AND the handle is claimed/moved. Once the new one is ready, delete the old, and the handle becomes available.
- New-vs-old channel question: if your channel has only ~1 video and ~4 views, don't bother transferring it — delete it and start fresh on the new Gmail.
- Niche/criteria: don't enter a niche a channel is already 4 months into (too late to be first). Faith/Bible niche = good audience. Follow the course's niche criteria.

## Warnings (worth keeping on file)
- AI "fake/fantasy" channels (misleading AI content, e.g. fake megastructures) get high views but LOW RPM, are flooded with competitors, and get demonetized easily (misleading content). For educational info videos: use AI as the production helper (map animation, imagery) but keep content factual — that's the safe way. High-accuracy map animation (like a certain hidden-estates channel) needs a human editor; Upwork ~$5-7/min for quality map/history channels; Vidrush map animator is not accurate enough for that tier.
