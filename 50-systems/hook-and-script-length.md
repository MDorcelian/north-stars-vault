# Hook and Script Length Policy

## Cold open (RESOLVED 2026-08-01, closes CONFLICTS.md #12)
Cold open remains the default, near-absolute rule. Some recent videos tested a hook variant, but main competitor Byte Sized Explainer ALWAYS does cold opens and that's the bar [G2]. Treat cold-open as standing policy; any hook test needs his sign-off per video, not a blanket exception.

## Script length (RESOLVED 2026-08-01, closes CONFLICTS.md #11)
He likes the 2,300-word ceiling as the target, but the scriptwriter (Maryam) sometimes cannot condense below that for a given topic [G2]. Working rule: 2,300 words is the aspirational ceiling to state in the brief, not a hard cutoff. If Maryam flags she can't condense further, that's an accepted exception, not a violation, don't force cuts that break the section. This matches the SOP's separately observed 2,800-3,000 word floor for 10-section scripts, both facts can be true at once (aim for 2,300, accept overflow when justified).
